# Tyn Packager 使用说明

把 Tyranor-Next 中已识别的 **Kirikiri 游戏**制作成独立安装的 APK（直装包）。

## 前置条件

1. 安装 **Tyranor-Next**（含游戏库只读共享接口的版本）；
2. 在 Tyranor 中添加并扫描游戏目录，确认游戏已出现在游戏库中；
3. 给 Tyn Packager 授予**所有文件访问权限**（首页有按钮引导）。

## 操作流程

### 1. 选择游戏

打开 Tyn Packager，首页会列出 Tyranor 中已识别的 Kirikiri 游戏。
点击任意一项进入制作页。

> 列表为空时，说明 Tyranor 中还没有扫描到 Kirikiri 游戏
> （目录下需要存在 `.xp3`、`startup.tjs` 或 `config.tjs`）。

### 2. 填写应用信息

| 字段 | 说明 |
|---|---|
| 应用名称 | 桌面显示的名字，默认取游戏标题 |
| 包名 | 默认 `com.tyn.games.<游戏名>`，可自定义 |

包名规则：至少两段、字母开头、只含字母数字下划线、不能是 Java 保留字。
包名必须与设备上已有应用不同，否则安装会冲突。

### 3. 设置图标

两种方式：

- **选择图片**：从相册选图，自动居中裁剪成正方形并缩放；
- **按游戏名抓取**：用游戏标题到 VNDB 搜索封面，点选候选即可。

可选尺寸：48 / 72 / 96 / 144 / 192 px。尺寸越大越清晰，APK 也会稍大。

不设置时会沿用 Tyranor 原图标。

### 4. 生成

点击「生成直装包」，依次执行：

1. **改造 APK** —— 改包名、应用名、图标
2. **内置游戏资源** —— 把游戏目录全部文件写入 APK 的 `assets/game/`
3. **签名** —— 用测试签名（设备内自签证书）签出

完成后可直接「安装」或「分享」。

## 关于签名

使用**测试签名**：应用内生成一张 RSA 2048 自签证书，保存在应用私有目录。

- 同一台设备多次打包**签名一致**，因此可以覆盖升级；
- 清除应用数据会导致签名变化，届时需先卸载旧包再安装；
- 这是测试用途的签名，不适合上架应用商店。

## 常见问题

**读不到游戏列表？**
检查 Tyranor 是否为含共享接口的版本，以及是否授予了权限。
首页状态卡会显示具体原因。

**游戏目录不可访问？**
确认已授予「所有文件访问权限」。游戏目录显示为 `content://` 而非真实路径时，
说明 Tyranor 侧未能换算路径，此时无法内嵌资源。

**生成的包装不上？**
- 包名与已安装应用冲突 → 换个包名；
- 旧包是其他签名 → 先卸载旧包。

**打包很慢 / 内存不足？**
游戏资源采用流式写入，不会一次性载入内存。
但超大游戏（数十 GB）仍会耗时较久，建议保持前台运行。
